Prime Relax Spa for Men - website (English + Arabic)
Pages: index, about, services, gallery, contact (.html)

HOW TO UPDATE AFTER THE SITE IS ONLINE
  Open js/config.js and edit:
   - the offer bar above the hero (add / change / delete offers; empty list hides it)
   - hero slides (photos and text, English and Arabic)
   - WhatsApp number, phone, opening hours, social links, map link
  Upload ONLY js/config.js to your hosting. It is loaded fresh on every visit, so
  visitors see changes straight away - no cache problems.
  New photo? Use a NEW file name (hero-5.jpg) and write it in config.js.

Hosting: upload the whole folder, main file index.html.
If you use Cloudflare or a CDN and ever see old content, purge its cache once.
